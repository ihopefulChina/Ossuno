# Ossuno 1.0.10

1.0.10 让应用图标跟上系统的深色、透明和色调外观，并补上超过 5 GiB 复制时的覆盖保护。

## 下载 Ossuno 1.0.10

- [Apple Silicon 版（M 系列芯片）](https://github.com/ihopefulChina/Ossuno/releases/download/v1.0.10/Ossuno-1.0.10-arm64.dmg)
- [Intel 版（x86_64）](https://github.com/ihopefulChina/Ossuno/releases/download/v1.0.10/Ossuno-1.0.10-x86_64.dmg)

两个安装包都需要 macOS 15 或更高版本。不确定芯片类型时，可在苹果菜单的「关于本机」中查看“芯片”或“处理器”。

## 重要：从旧版手动升级

**从 1.0.4 或更早版本升级到 1.0.5 或更高版本必须手动下载并安装。**

1.0.5 将 Bundle ID 从 `studio.ossuno.oss` 更正为 `app.ihopeful.Ossuno`。Sparkle 不能用不同 Bundle ID 的新应用直接替换旧应用，因此旧版上的更新检查只会显示迁移说明并引导打开下载页，不会执行自动替换。1.0.10 继续使用 `app.ihopeful.Ossuno`；已安装 1.0.5、1.0.6、1.0.7、1.0.8 或 1.0.9 的用户可通过「Ossuno → 检查更新…」升级。

1. 退出正在运行的旧版 Ossuno。
2. 下载与 Mac 芯片匹配的 1.0.10 DMG。
3. 打开 DMG，将 Ossuno 拖入「应用程序」，并在 Finder 询问时确认替换旧副本。
4. 首次启动 1.0.10，按下方步骤处理 Gatekeeper 提示。

1.0.5 起会迁移旧应用的偏好与账号显示配置，并继续查找原服务名下的钥匙串凭证。由于应用身份已变更，macOS 可能会要求你允许 1.0.10 访问这些钥匙串项目；允许后无需重新输入 AccessKey。通知权限也可能针对新 Bundle ID 再次弹出授权请求。完成迁移后，后续使用 `app.ihopeful.Ossuno` 的版本可恢复正常的应用内更新流程。

## 改进

- 应用图标支持 macOS 的深色、透明和色调外观。深色外观使用纯黑背景，文件夹和托盘保持原样。
- 官网在系统暗色模式下改用同一套纯黑图标，不再继续显示亮蓝图标。
- 超过 5 GiB 的同 Bucket 复制、移动和重命名会在分片提交前再次核对目标；禁止覆盖时，Complete 请求也带上 `x-oss-forbid-overwrite`。
- Apple Silicon 与 Intel 发布构建号分别更新为 23 和 22。

## 系统要求

- Apple Silicon 或 Intel Mac
- macOS 15 或更高版本

## 分发方式与首次打开

两个 DMG 均采用 ad-hoc 代码签名（没有开发者身份），不是 Developer ID 签名，且未经 Apple 公证。因此 macOS 无法验证开发者或确认安装包已经过 Apple 恶意软件检查，首次打开通常会触发 Gatekeeper。

1. 双击 Ossuno 尝试打开一次。
2. 若 macOS 阻止运行，打开「系统设置 → 隐私与安全」，滚动到“安全性”，点击「仍要打开」。
3. 在再次出现的警告中点击「打开」；系统可能要求密码或 Touch ID。以后可正常双击打开。

仅在确认安装包来自本仓库的 GitHub Releases 时放行。详细背景见 [Apple 的安全打开说明](https://support.apple.com/zh-cn/102445)。
