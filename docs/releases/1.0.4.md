# Ossuno 1.0.4

这是一次界面更新，让主窗口更接近访达：侧边栏铺到窗口底部，传输状态留在内容区，并修正添加账号「高级」表单的行距。

## 下载 Ossuno 1.0.4

- [Apple Silicon 版（M 系列芯片）](https://github.com/ihopefulChina/Ossuno/releases/latest/download/Ossuno-1.0.4-arm64.dmg)
- [Intel 版（x86_64）](https://github.com/ihopefulChina/Ossuno/releases/latest/download/Ossuno-1.0.4-x86_64.dmg)

两个安装包都需要 macOS 15 或更高版本。不确定芯片类型时，可在苹果菜单的「关于本机」中查看“芯片”或“处理器”。

## 改进

- 侧边栏铺满窗口高度，不再被底栏横切；传输状态条只出现在内容区，路径栏与状态栏共用访达式底栏高度。
- 添加账号的「高级」展开后使用与其他分区相同的表单行：STS Token、自定义 Endpoint、CDN 域名各自成行，说明文字放到分区页脚。
- 列表视图改用访达式交替行背景；侧边栏图标使用分层 SF Symbols。

## 系统要求

- Apple Silicon 或 Intel Mac
- macOS 15 或更高版本

## 分发方式与首次打开

两个 DMG 均采用 ad-hoc 代码签名（没有开发者身份），不是 Developer ID 签名，且未经 Apple 公证。因此 macOS 无法验证开发者或确认安装包已经过 Apple 恶意软件检查，首次打开通常会触发 Gatekeeper。

1. 打开 DMG，把 Ossuno 拖进「应用程序」，然后双击 Ossuno 尝试打开一次。
2. 若 macOS 阻止运行，打开「系统设置 → 隐私与安全」，滚动到“安全性”，点击「仍要打开」。
3. 在再次出现的警告中点击「打开」；系统可能要求密码或 Touch ID。以后可正常双击打开。

仅在确认安装包来自本仓库的 GitHub Releases 时放行。详细背景见 [Apple 的安全打开说明](https://support.apple.com/zh-cn/102445)。
