隐私说明

Ossuno 不做分析追踪，也没有自己的账号系统。它只保存连接阿里云 OSS、完成文件操作所需的本机数据。

更新日期：2026 年 9 月 4 日

保存在这台 Mac 上的数据

AccessKey Secret 与 STS Token 保存在 macOS 钥匙串。账号显示设置、地域、Endpoint、CDN 域名、默认权限、收藏位置、界面偏好与经过清理的传输历史保存在应用的本地容器或 Application Support 中。1.0.5 更正 Bundle ID 后会迁移旧偏好与账号显示配置，并继续查找原服务名下的钥匙串凭证；macOS 可能会要求允许新应用身份访问这些项目，也可能再次请求通知权限。

传输历史不会保存 OSS 客户端实例、请求授权头、Secret、Token 或带签名的公开链接。为重新访问用户选择的文件或目录，系统安全作用域书签可能包含由 macOS 管理的本地文件引用。

网络连接

Ossuno 直接连接你选择或配置的阿里云 OSS Endpoint，以列出、上传、下载和整理对象。请求会包含 OSS 验证所需的 AccessKey ID、签名以及可选 STS Token。

软件更新会访问 GitHub Pages 获取更新源（appcast），并从 GitHub Releases 下载安装包。Ossuno 不包含广告 SDK、行为分析、崩溃上报或自建遥测服务。

诊断信息

“帮助 → 复制诊断信息”只生成版本、构建号、macOS、架构、更新域名、账号与传输数量，以及非敏感功能设置。它不包含账号名、AccessKey ID、Bucket、对象键、本地路径、URL、请求 ID、Secret 或 Token。

诊断摘要只会复制到剪贴板，不会自动发送。是否粘贴到 Issue 或其他位置由你决定。

删除与保留

在 Ossuno 中删除账号会移除这台 Mac 上对应的账号配置与钥匙串凭证，不会删除云端 Bucket 或对象。卸载应用前，可先在设置中删除账号；界面偏好和传输历史可在系统的应用数据目录中移除。

系统隐私清单

仓库中的 PrivacyInfo.xcprivacy 声明 Ossuno 不追踪用户、不收集数据，并仅以应用功能目的访问 UserDefaults 类 API。

联系

一般问题请查看支持页面。尚未公开的安全问题请使用 GitHub 的私密安全报告，不要把真实凭证或存储路径放进公开 Issue。
